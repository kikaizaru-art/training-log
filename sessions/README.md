# Sessions ディレクトリ

各筋トレセッションの記録を蓄積する場所。

## 命名規則

`YYYY-MM-DD_<routine>.md`

例:
- `2026-05-05_上半身push.md`
- `2026-05-07_脚＋体幹.md`
- `2026-05-09_Pull＋仕上げ.md`

## 作成方法

`_template-session.md`（親ディレクトリ）を雛形に、Claude が対話で生成。
